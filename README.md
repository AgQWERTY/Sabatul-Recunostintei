# Ai un loc în planul Lui

A small two-step Romanian website:

1. Visitor enters their name.
2. The site reveals a personalized message and Bible verse.

## Run locally

Just open `index.html` in a modern browser.

No build process, framework, database, or server is required.

## Deploy

Upload the three website files (`index.html`, `style.css`, `script.js`) to any static hosting service such as GitHub Pages, Netlify, or Vercel.

The site works entirely in the browser; the visitor's name is not sent to a server.
